<h2>How it works</h2>
<p class="rf-lede">One loop, running in the background of every session. Same engine and knowledge base across Claude Code, Codex CLI and GitHub Copilot.</p>

<FlowSteps />

<h2>Install and first run</h2>
<p class="rf-lede">The engine is a Python package. Install it with <code>uv</code>, then create a knowledge base and search it.</p>

```bash
uv tool install --upgrade --torch-backend cpu \
  'git+https://github.com/stevengonsalvez/plugly-reflect-memory.git[graph]'
plugly-reflect-memory --version
plugly-reflect-memory init
plugly-reflect-memory search "how did we fix the tokio panic"
```
