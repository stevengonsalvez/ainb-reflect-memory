## What to try

| Try | Where | What happens |
|---|---|---|
| Search | Box in the header: type `postgres` | Lexical BM25-lite ranking over title, tags and body. Cards show `match` and `browse` scores. |
| Graph view | **Graph** tab | Two-layer graph: memory nodes plus entity nodes. Drag nodes, scroll to zoom, click a memory node to open it. Toggle entities and labels. |
| Filters | Left sidebar | Facet by confidence, type, scope and tag. Combine with search and the sort menu (newest, recall score, title). |
| Curation drawer | Click any card | Edit confidence, see related memories and extracted entities, or **Archive** the note. |
| Superseded chains | **Superseded** tab | Notes replaced by newer ones, shown newest to oldest. |
| Archived and restore | Archive a note, then open **Archived** | The note leaves the list, the graph and the stats. **Restore** brings it back. |
| Compress queue | **select**, tick two or more cards | **Queue for compression** marks the group for the `/reflect` consolidate step. |
| Stats | **Stats** tab | Counts by confidence, type, scope and tag. They update as you archive and restore. |

:::note
Against a real knowledge base the same UI runs as `reflect serve` and its curation actions edit your markdown notes on disk. See the [memory browser guide](/ainb-reflect-memory/guides/memory-browser/) and the [serve API reference](/ainb-reflect-memory/reference/serve-api/).
:::
